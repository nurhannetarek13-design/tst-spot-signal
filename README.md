# TST Spot Signal

Signal-only Binance Spot scanner for liquid USDT pairs.

- No leverage
- No automatic trading or order placement
- Maximum planned position: 5 USDT
- Maximum planned risk: 0.50 USDT
- Scheduled scan: every 15 minutes
- Telegram alerts only when all configured checks pass

Runtime secrets remain stored in Cloudflare and are never committed to GitHub.
